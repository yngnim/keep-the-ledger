# 보스 배틀 연대기 조사

## 조사 기준

- 원본: `KTHO_Boss_Battles_Rulebook_KO.pdf`
- 보스 배틀 본편은 기본판 결말 이후의 이야기다.
- 본편 연대기는 3개 챕터, 10개 시나리오(21-30번)로 구성된다.
- H1-H3은 본편 연대기가 아닌 연말 특선 보너스 시나리오다.
- 스토리는 웹앱에 옮길 때 시나리오 원문의 문장을 그대로 사용하고 요약문으로 대체하지 않는다.

## 보스 배틀 연대기의 개정 규칙

1. 챕터 시작 시 난이도에 따라 신참 카드 4/8/12장을 추가한다.
2. 같은 챕터에서 패배한 시나리오마다 이후 시나리오의 신참 카드를 2장씩 더 추가한다. 최대치는 12장이다.
3. 승패와 관계없이 시나리오 하나가 끝나면 다음 시나리오로 넘어간다.
4. 챕터의 마지막 시나리오에서 승리해야 챕터 보상을 해금한다.
5. 시나리오에서 NPC로 사용하는 몬스터 클랜은 플레이어가 선택할 수 없다.
6. 단일 게임에서도 시나리오의 조건을 충족하면 카드팩을 해금할 수 있다.

위 내용은 룰북의 원 규칙이다. 웹앱에서는 승패 이력, 패배 횟수, 패배에 따른 신참 증가를 별도 상태로 추적하지 않는다. 시나리오 진행은 단순한 연대기 순서로 취급하고, 자동화는 챕터 마지막 시나리오를 클리어했을 때 해금되는 시스템 능력에만 적용한다.

## 30번 시나리오의 분기

### 드래곤이 웨이브 1 종료까지 갇혀 있는 경우 - 31쪽

- `불 뿜는 괴수` 분기로 진행한다.
- 드래곤에게 피해 25를 주거나, 강아지 6마리를 드래곤이 있는 방으로 데려가면 승리한다.
- I는 피해로 쓰러뜨렸을 때가 아니라 **강아지로 드래곤을 진정시켰을 때만** 개봉한다.
- I의 해금 결과는 강아지 클랜이다.

### 웨이브 1 종료 전에 드래곤을 풀어준 경우 - 32쪽

- `최후의 저항` 분기로 진행한다.
- 뱀파이어 왕 빈센트에게 피해 30을 주어 악마의 보석을 파괴하면 승리한다.
- 이때 B를 개봉하며 박쥐 클랜을 해금한다.

어느 분기에서든 30번 시나리오를 클리어하면 3장 보상 `전설 레벨`을 자동 해금한다. I와 B의 카드팩 개봉 여부는 웹앱에서 기록하지 않으며, 각각의 조건만 표시한다.

## 챕터 종료 보상

| 완료 조건 | 보상 | 웹앱 자동 적용 |
|---|---|---|
| 24번 클리어 | 장치 설계도 | 해금 능력으로 등록하고 이후 화면에서 활성화. G 개봉은 조건 안내만 표시 |
| 27번 클리어 | 고철로봇 설계자 | 이후 던전 세팅에 고철로봇 준비를 자동 추가. 수호자 방이 없는 시나리오에서만 표시 |
| 30번 클리어 | 전설 레벨 | 이후 플레이 보조에 "전리품을 전술 카드 더미 맨 위에 놓을 수 있음"을 활성 능력으로 표시 |

`장치 설계도`는 챕터 보상이면서 동시에 밀봉 카드팩 G를 여는 보상이다. `고철로봇 설계자`와 `전설 레벨`은 카드팩 없이 지속 능력으로 해금된다.

카드팩의 정확한 카드 장수와 물리적 구성은 룰북 본문에 열거되어 있지 않다. 룰북 2쪽은 각 카드팩 외부에 카드 구성과 수량이 적혀 있다고 안내한다. 웹앱은 카드팩의 개봉 여부나 해금 결과를 저장하지 않고, 필요한 시점에 `팩 문자`와 `개봉 조건`만 안내한다.

## 웹앱 상태 모델

- `bossChronicleProgress`: 21-30의 연대기 표시 위치
- `bossChapterRewards`: 장치 설계도 / 고철로봇 설계자 / 전설 레벨

`openedPacks`, `unlockedClans`, `bossChapterLosses`는 만들지 않는다. 30번의 분기는 현재 플레이 화면에서 필요한 책자 쪽과 기믹을 바꾸는 일시 상태로만 사용하고 저장하지 않는다.

## 화면 배치 제안

### 홈 연대기 트랙

- 기본판 1-20 다음에 보스 배틀 21-30을 3개 챕터로 표시한다.
- 자동 해금된 챕터 능력만 기존 해금 능력 영역에서 바로 볼 수 있게 한다.
- 카드팩 목록이나 개봉 상태 UI는 만들지 않는다.

### 던전 세팅

- 금지 클랜과 필요한 시나리오 카드를 표시한다.
- 30번에는 "게임 준비 전에 K를 개봉" 조건을 게임 준비 최상단에 표시하되 완료 체크는 받지 않는다.
- 신참은 기존 난이도 선택의 4/8/12장만 사용하고 패배 보정은 자동화하지 않는다.
- `고철로봇 설계자`가 해금된 이후에는 조건에 맞는 시나리오의 준비 목록에 고철로봇 준비를 자동 추가한다.

### 플레이 보조

- 24번: 웨이브 1 종료 전에 D 개봉 조건을 고정한다.
- 29번: 웨이브 2 전환 시 "마녀 플레이어가 있다면 C 개봉 후 신시아로 교체" 조건을 표시한다.
- 30번: 웨이브 1 종료 시 드래곤 해방 여부를 선택해 31쪽 또는 32쪽 기믹으로 전환한다.
- 나머지 팩은 해당 시나리오의 승리 조건 옆에 개봉 조건을 안내할 뿐, 개봉 여부는 묻거나 저장하지 않는다.
- 해금된 `전설 레벨`은 이후 모든 플레이 보조 화면의 능력 영역에 자동 표시한다.

### 룰북 이미지

- 챕터 개요와 보상: 10쪽
- 시나리오 21-28: 각 2쪽짜리 이미지 묶음
- 시나리오 29: 27-29쪽
- 시나리오 30: 30쪽 준비 화면과 분기에 따라 31쪽 또는 32쪽
