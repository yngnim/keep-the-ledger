# 보스 배틀 연대기 조사

## 조사 기준

- 원본: `KTHO_Boss_Battles_Rulebook_KO.pdf`
- 보스 배틀 본편은 기본판 결말 이후의 이야기다.
- 본편 연대기는 3개 챕터, 10개 시나리오(21-30번)로 구성된다.
- H1-H3은 본편 연대기가 아닌 연말 특선 보너스 시나리오다.
- 스토리는 웹앱에 옮길 때 시나리오 원문의 문장을 그대로 사용하고 요약문으로 대체하지 않는다.

## 보스 배틀 연대기의 개정 규칙

1. 챕터 시작 시 난이도에 따라 신참 카드 4/8/12장을 추가한다.
2. 같은 챕터에서 패배한 시나리오마다 이후 시나리오의 신참 카드를 2장씩 더 추가한다. 최대치는 12장이다.
3. 승패와 관계없이 시나리오 하나가 끝나면 다음 시나리오로 넘어간다.
4. 챕터의 마지막 시나리오에서 승리해야 챕터 보상을 해금한다.
5. 시나리오에서 NPC로 사용하는 몬스터 클랜은 플레이어가 선택할 수 없다.
6. 단일 게임에서도 시나리오의 조건을 충족하면 카드팩을 해금할 수 있다.

현재 기본판 트래커의 "실패하면 진행하지 않음" 처리와 2-4번 규칙이 다르다. 보스 배틀 진행도에는 `현재 시나리오`, `이번 챕터 패배 횟수`, `챕터 보상 획득 여부`를 각각 저장해야 한다.

## 30번 시나리오의 분기

### 드래곤이 웨이브 1 종료까지 갇혀 있는 경우 - 31쪽

- `불 뿜는 괴수` 분기로 진행한다.
- 드래곤에게 피해 25를 주거나, 강아지 6마리를 드래곤이 있는 방으로 데려가면 승리한다.
- I는 피해로 쓰러뜨렸을 때가 아니라 **강아지로 드래곤을 진정시켰을 때만** 개봉한다.
- I의 해금 결과는 강아지 클랜이다.

### 웨이브 1 종료 전에 드래곤을 풀어준 경우 - 32쪽

- `최후의 저항` 분기로 진행한다.
- 뱀파이어 왕 빈센트에게 피해 30을 주어 악마의 보석을 파괴하면 승리한다.
- 이때 B를 개봉하며 박쥐 클랜을 해금한다.

일반 규칙에 따르면 어느 분기든 30번 시나리오에서 승리하면 3장 보상 `전설 레벨`을 해금한다. 하지만 I와 B는 서로 다른 분기에 있으므로, 한 번의 플레이로 둘을 모두 해금할 수 없다.

## 챕터 종료 보상

| 완료 조건 | 보상 | 처리 |
|---|---|---|
| 24번 승리 | 장치 설계도 | G를 개봉하고 새 장치 카드를 장치 카드 더미에 추가 |
| 27번 승리 | 고철로봇 설계자 | 이후 게임 준비에 고철로봇 토큰과 장치 카드 더미를 추가. 수호자 방이 없는 시나리오에서만 사용 |
| 30번 승리 | 전설 레벨 | 전리품 획득 시 버린 카드 더미 대신 자신의 전술 카드 더미 맨 위에 놓을 수 있음 |

`장치 설계도`는 챕터 보상이면서 동시에 밀봉 카드팩 G를 여는 보상이다. `고철로봇 설계자`와 `전설 레벨`은 카드팩 없이 지속 능력으로 해금된다.

카드팩의 정확한 카드 장수와 물리적 구성은 룰북 본문에 열거되어 있지 않다. 룰북 2쪽은 각 카드팩 외부에 카드 구성과 수량이 적혀 있다고 안내한다. 따라서 웹앱에는 우선 `팩 문자`, `개봉 조건`, `해금 결과`, `개봉 여부`를 기록하고, 카드 장수는 실제 팩 외부 표기를 확인한 뒤 추가하는 것이 안전하다.

## 웹앱 상태 모델 제안

- `bossChronicleStage`: 21-30의 현재 위치
- `bossChapterLosses`: 챕터별 패배 횟수
- `bossChapterRewards`: 장치 설계도 / 고철로봇 설계자 / 전설 레벨
- `openedPacks`: A-O 각각의 개봉 여부
- `unlockedClans`: 팩 해금 결과와 별도로 저장
- `scenarioBranches`: 30번의 드래곤 격노 / 드래곤 해방 분기 기록

카드팩 상태는 연대기 진행도에서 자동으로 추론하면 안 된다. 단일 게임에서도 해금할 수 있고, C·I·B처럼 조건 또는 분기에 따라 같은 시나리오 완료 여부와 다른 결과가 생기기 때문이다.

## 화면 배치 제안

### 홈 연대기 트랙

- 기본판 1-20 다음에 보스 배틀 21-30을 3개 챕터로 표시한다.
- 각 챕터 완료 보상과 개봉한 카드팩을 바로 볼 수 있게 한다.
- 미개봉 팩은 `???`와 팩 문자만 표시하고 클릭을 막는다.

### 던전 세팅

- 금지 클랜과 필요한 시나리오 카드를 표시한다.
- 30번에는 K 개봉 안내를 게임 준비 최상단에 표시한다.
- 보스 배틀용 신참 수량은 기본 4/8/12에 이번 챕터의 패배 보정 `+2 × 패배 횟수`, 최대 12를 적용한다.

### 플레이 보조

- 24번: 웨이브 1 종료 전에 D 개봉 경고를 고정한다.
- 29번: 웨이브 2 전환 시 마녀 선택 여부를 확인하고 C 개봉/신시아 교체 안내를 표시한다.
- 30번: 웨이브 1 종료 시 드래곤 해방 여부를 선택해 31쪽 또는 32쪽 기믹으로 전환한다.
- 나머지 팩은 승리 조건 달성 후 결과 화면에서 개봉을 안내한다.

### 룰북 이미지

- 챕터 개요와 보상: 10쪽
- 시나리오 21-28: 각 2쪽짜리 이미지 묶음
- 시나리오 29: 27-29쪽
- 시나리오 30: 30쪽 준비 화면과 분기에 따라 31쪽 또는 32쪽
